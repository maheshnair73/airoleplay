## 🎯 What You're Creating

A coaching task that:
- Makes reps read training materials FIRST
- Then practice with AI
- Then submit for your review

## 📋 The 4 Tabs Explained

### Tab 1️⃣: Task Details
**What it is:** The basic info
- Title: "Product Demo Practice"
- Type: Video/Audio/Screen
- Scenario: What should they do?
- Duration: How long?

**Time needed:** 2 minutes

---

### Tab 2️⃣: Training Materials ⭐ NEW!
**What it is:** The study materials + AI practice

**Two key sections:**

#### Section A: AI Roleplay (Optional)
```
┌──────────────────────────────────────┐
│ Select AI Client (Optional)          │
│ ┌──────────────────────────────────┐ │
│ │ Sarah Johnson - VP of Sales      │ │ ← Pick an AI persona
│ └──────────────────────────────────┘ │
└──────────────────────────────────────┘
```

#### Section B: Training Materials
```
┌─────────────────────────────────────────────┐
│ ⚙️ Require Material Review Before Starting │
│    [●○○○○○○○○○] Toggle ON/OFF              │
│                                             │
│ ON  = Must read before submitting          │
│ OFF = Optional reference materials         │
└─────────────────────────────────────────────┘

┌─────────────────────────────────────────────┐
│ Select Materials:                           │
│                                             │
│ ☑ Product Features Guide                   │
│   Product Knowledge | Document             │
│                                             │
│ ☑ Objection Handling Playbook              │
│   Sales Methodology | Document             │
│                                             │
│ ☐ Pricing Calculator                       │
│   Product Knowledge | Spreadsheet          │
└─────────────────────────────────────────────┘
```

**Time needed:** 1 minute

---

### Tab 3️⃣: Assignment
**What it is:** Who should do this task?

- Pick specific people, OR
- Leave empty = everyone gets it

**Time needed:** 30 seconds

---

### Tab 4️⃣: Evaluation
**What it is:** How you'll grade them

Default criteria (keep or edit):
- Clarity
- Confidence
- Value Proposition

**Time needed:** 30 seconds

---

## ⚡ Quick Example

**Goal:** Train team on new pricing model

```
Tab 1: Task Details
  ├─ Title: "New Pricing Model Practice"
  ├─ Type: Audio Recording
  ├─ Scenario: "Explain our new pricing tiers to a mid-market prospect"
  └─ Duration: 5 minutes

Tab 2: Training Materials
  ├─ AI Client: "Budget-Conscious CFO"
  ├─ Required Reading: ON
  └─ Materials:
      ├─ ☑ New Pricing Guide 2024
      └─ ☑ ROI Calculator

Tab 3: Assignment
  └─ Everyone (leave empty)

Tab 4: Evaluation
  └─ Keep defaults + Add "Pricing Accuracy"

Click "Create Task" → Done! ✅
```

## 💡 Pro Tips

### Tip 1: Start with Required Reading ON
For important topics, always require reading. You can't assume reps studied.

### Tip 2: Always Assign an AI Client
Free practice! Even if reps think they know the material, AI catches gaps.

### Tip 3: Keep Materials Short
2-3 documents max per task. Long reading = low completion.

### Tip 4: Match AI to Topic
- Pricing discussions? → CFO persona
- Technical demos? → CTO persona
- General sales? → VP of Sales

### Tip 5: Test First
Create a task and assign it to yourself. Experience what reps will see.
